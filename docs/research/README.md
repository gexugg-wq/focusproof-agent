# Research And Acceptance Records

This directory keeps only records that still explain the current system or
prove a current acceptance boundary:

- `OPENHANDS_SDK_FEASIBILITY.md` and
  `OPENHANDS_CONVERSATION_CORE_INTEGRATION.md`: direct-reuse decisions.
- `PERSISTENCE_RUNTIME_HARDENING_REPORT.md`: durable product/runtime boundary.
- `AI3_2_UNIFIED_LEARNING_UX_REPORT.md`: current unified learning flow.
- `AI4C_PRODUCTION_READINESS_REPORT.md`: production-readiness matrix.
- `AI5_IMAGE_GATE_REPORT.md` and `AI5_8_FINAL_ACCEPTANCE_REPORT.md`: image
  evidence and final media acceptance.
- `GENERAL_CORE_GATE_REPORT.md` and `GENERAL_CORE_P1_REPAIR_REPORT.md`: current
  general-core gate and repair closure.
- `MONAD_PLUGIN_REMOVAL_REPORT.md`: proof that the retired optional plugin no
  longer participates in the general product path.

Per-task plans, fix-round diaries, generated screenshots, and superseded
reports are intentionally absent from the working tree. Git history remains the
source for that process archaeology.
